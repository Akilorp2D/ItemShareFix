# ItemShareFix — кратко на русском

ItemShareFix — мод-патч/расширение для ItemShare в Risk of Rain 2. Он не заменяет ItemShare.

Основные возможности:

- персонально скрывает уже завершённое для локального игрока представление shared pickup, не уничтожая его для остальных;
- показывает локальные метки только для предметов/Command-выборов, которые ещё нужны этому участнику;
- поддерживает Detailed и Compact режимы, группировку плотных куч и off-screen агрегацию;
- корректно учитывает состояние Support Drone / Remote Operation по точному runtime-сигналу;
- откладывает право полностью мёртвого игрока на предмет до безопасной точки восстановления;
- отличает настоящий disconnect от смерти и временного уничтожения сетевого объекта;
- позволяет включать/выключать sharing временных предметов через `ShareTemporaryItems`; для нового конфига значение по умолчанию — `false` (OFF), а уже сохранённое значение при обновлении не перезаписывается;
- позволяет настраивать размеры, прозрачность, расстояния, счётчики и цвета меток;
- может опционально регистрировать настройки в Risk Of Options, но основной источник настроек — BepInEx config.
- локализует собственный текст маркеров на 11 официальных языков интерфейса RoR2: английский, французский, итальянский, немецкий, испанский, японский, корейский, португальский (Бразилия), русский, упрощённый китайский и турецкий; названия предметов остаются игровыми через RoR2 localization, а неизвестный язык откатывается на английский.

Обязательные зависимости: BepInExPack 5.4.2121, PickupShareApi 1.0.0 и ItemShare 1.7.1.
